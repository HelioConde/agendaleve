# AgendaLeve

Protótipo de agendamento para pequenos negócios. Permite registrar e cancelar horários, bloqueia datas passadas e evita dois atendimentos no mesmo horário. Os próximos atendimentos aparecem em ordem cronológica.

Os dados ficam no navegador. Lembretes por WhatsApp, contas, pagamento e sincronização entre dispositivos ainda não estão conectados.
