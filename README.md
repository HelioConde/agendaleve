# AgendaLeve

Protótipo de agendamento para pequenos negócios. Permite registrar e cancelar horários, bloqueia datas passadas, respeita o expediente das 8h às 19h e impede sobreposição entre atendimentos considerando a duração selecionada. Os próximos horários aparecem em ordem cronológica.

Os dados ficam no navegador. Lembretes por WhatsApp, contas, pagamento e sincronização entre dispositivos ainda não estão conectados.
